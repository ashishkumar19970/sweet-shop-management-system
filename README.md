# 🍬 Sweet Shop Management System

A professional enterprise-level Java Backend project developed using **Spring Boot**, following the complete **Software Development Life Cycle (SDLC)**.

This project is designed as a real-world backend application where every phase—from Requirement Gathering to Deployment—is documented and implemented following company standards.

---

# 📌 Project Overview

The Sweet Shop Management System is an online application that allows customers to browse sweets, place orders, make online payments, and track their order history.

The system also provides an Admin Panel to manage products, categories, inventory, customers, and orders.

---

# 🎯 Project Objectives

- Build a secure backend application.
- Follow Enterprise SDLC Process.
- Learn Professional Java Backend Development.
- Implement REST APIs using Spring Boot.
- Secure APIs using JWT Authentication.
- Manage Database using MySQL.
- Follow Clean Code and Layered Architecture.
